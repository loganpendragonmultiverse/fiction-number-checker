# Development scope

The tool extracts explicit Arabic-numeral facts from four local manuscript formats, performs transparent unit normalization, supports explicit subject filters, and produces review groups without declaring contradictions.

Coreference resolution, chronology inference, semantic fact checking, cloud processing, and manuscript rewriting are intentionally excluded.

Version 1.1 adds bounded English number-word extraction in age/count/duration contexts, retaining original evidence and refusing partial larger phrases.
